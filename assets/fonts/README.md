# Open Graph font

`source-serif-4-regular.ttf` and `source-serif-4-bold.ttf` are Source Serif 4
from [Adobe's official release branch](https://github.com/adobe-fonts/source-serif/tree/release/TTF).
They are used only while `next/og` renders the site's static link-cover images;
the live site continues to load the same family through `next/font`.

Source Serif 4 is licensed under the SIL Open Font License 1.1; the license is
included beside the font as `OFL.txt`.
