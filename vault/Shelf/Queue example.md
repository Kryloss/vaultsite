A placeholder so the shelf's **Up next** row and the *To read* badge are
visible in `npm run dev`. It is `draft: true`, so it never reaches the live
site.

To use this for real, put `status: want` in any shelf note's frontmatter and
delete this file. Books get *To read*; films, shows and videos get *To watch*.
Use `status: reading` (or `watching`) for something you're part-way through —
that badges the cover in place, without adding a row.
