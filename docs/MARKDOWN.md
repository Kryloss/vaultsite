# Markdown pipeline and bilingual rendering

`lib/markdown.ts` turns Obsidian markdown into HTML at build time. The pipeline order is in `docs/ARCHITECTURE.md → Rendering pipeline`; diagrams and image notes are `docs/EXCALIDRAW.md`. Reasons: `docs/DECISIONS.md` #4, #10, #11, #17, #23, #28, #32, #43, #69–#72, #87.

## Invariants

- Everything resolves at build time. Extend the existing build-time pipeline rather than adding client-side Markdown or highlighting work.
- `preprocessObsidian` is regexes over raw text, so **code is masked first**: `maskCode()` swaps fenced blocks and inline spans for private-use-area sentinels and `unmaskCode()` restores them, so a note documenting `[[wiki links]]` in backticks is not rewritten (#4).
- Raw HTML helpers emit ONE line: a blank line inside raw HTML terminates the markdown HTML block. And raw HTML standing alone on a line OPENS an HTML block that runs until the next blank line, so a block-level tag emitted by a helper needs blank lines around it, but only when `standalone()` says the embed really is alone on its line (#10).
- **Self-theming SVGs are inlined into the page** (`inlineSelfThemingSvg`, styles namespaced to `#d-<filename>` by `scopeSvgCss`) — through `<img>` the browser caches the rasterized image and freezes its `prefers-color-scheme` at first decode. Only SVGs whose source contains `prefers-color-scheme` are inlined, capped at 64KB (`MAX_INLINE_SVG`; `validate-image-notes` blocks a diagram over it). **The swap runs on the FINAL HTML, not during preprocessing** — inlined earlier, the wiki-link and progress regexes rewrite the diagram's own labels and a `<span>` inside SVG breaks the parser out of foreign content. Two-file Excalidraw exports still use `<img>`. Verify structurally on the built HTML: `<svg>`/`</svg>` balanced, no `<p><text` inside a diagram (#10).
- `themedImg()` stamps `loading="lazy"` on both halves of a theme or language swap; a hidden lazy image is never fetched, which is a latent bug for the first bilingual raster embed (#110). Spine art and any other bilingual IMAGE that swaps by CSS must not be lazy.
- Heading ids are namespaced per language (`rehypeHeadings` in `lib/toc.ts`, after `rehype-slug`): the Ukrainian body renders with `idPrefix: "uk-"`, so two languages in one document never mint the same id (#17). The TOC label is read BEFORE the `#` anchor is appended. Anchors are off in the RSS feed. Spoiler ids and footnote ids run through the same prefix (#23, #28).
- Output is injected via `dangerouslySetInnerHTML` — safe because the only markdown author is the site owner.

## Features

- **Wiki links** resolve across ALL sections via `getWikiIndex()` (file name, title, slug, or `aliases:` frontmatter — case-insensitive). Unknown targets fall back to same-section slug. For links to SECTION pages use `[[Folder/main|Label]]` — it resolves on the site AND opens the right file in Obsidian.
- **Callouts**: Obsidian `> [!note] Title` → styled `.callout` divs (colors per type in globals.css; callouts keep their four hues). Two types are intercepted before that: `[!spoiler]` blurs its body until clicked (its title is a second label on the same checkbox, so it can be blurred again — #23), and `[!pull]` becomes a margin pull-quote (`docs/READING.md`). Inline `||spoiler||` works too; both are a checkbox and label, no JS.
- **Progress bars**: `[progress:: 45]` inline in any note → styled bar + percent label (plain text in Obsidian).
- **Code blocks**: highlighted at build time by Shiki (`lib/highlight.ts` + `rehypeCodeBlocks`), dual themes as `--shiki-light`/`--shiki-dark` variables, wrapped in `<figure class="code-block">`. Optional filename header via ` ```bash title="scan.sh" ` (a bare `scan.sh` after the language works too); the info string is copied onto the element by `rehypeCodeMeta` BEFORE `rehype-raw` runs, and comes out renamed `dataMeta` — both spellings are read (#11). Shell fences (`SHELL_LANGS`/`isShell()`) render as a terminal: `data-terminal` on the figure, three grey dots in the header, and a header even with no title — grey, not traffic lights (#65). Languages must be listed in `LANGS` in `lib/highlight.ts` — unknown ones fall back to plain text; loading Shiki's full bundle would pull ~10MB of grammars into every build. Copy button injected by `components/CodeCopy.tsx`, centred against the code header whose line-height is stated rather than inherited.
- **Embeds**: standalone Apple Music and YouTube links become players (`lib/youtube.ts`, served from youtube-nocookie.com; handles watch/youtu.be/shorts/live URLs). Apple Music details: `docs/MUSIC.md → The players`.
- **Figures/lightbox**: standalone images with alt text render as figure+figcaption; sized image embeds ≤128px (`![[me.jpeg|93]]`) render as circular avatars (`.avatar`), larger sizes keep the rounded-rectangle style. Caption `EN :: UK` splits by language.
- **Image dimensions and responsive images**: `sync-assets.mjs` writes `.image-manifest.json` (blur placeholder + `w`/`h` + `dom` colour per raster) and 256/672/1344px WebP copies beside each raster (never touching the originals) with a ready-made `srcset`; `rehypeImageSize` stamps `width`/`height`/`srcset` on content images with a `sizes` matching the prose column (or the embed's own width) — a `srcset` without `sizes` makes the browser pick the largest candidate. Explicitly sized embeds keep their size. Blur placeholders are the `<img>`'s own `background-image` (#19, #32, #43). Shelf and people covers carry it via `coverSrcSet`; `srcSetFor()` in `lib/blur.ts`. `lib/blur.ts` touches `fs`, so values are passed as props to anything rendered by a client component.
- **Fact tables** (`rehypeFactTables`, `rehypeLiftFacts`) and the clipped `## At a glance` heading: `docs/SHELF.md → Entry page`. Detection of a fact block is on the hast node's `data`, never a serialized attribute, so People notes keep their card (#121).
- **Diagrams**: `![[Drawing.excalidraw]]` embeds resolve to the Excalidraw plugin's exported SVG (theme-aware if light+dark exported); AI diagrams are self-theming `.svg` files embedded like images. Resolver: `getAssetIndex()` in `lib/vault.ts` (basename→URL, vault-wide) + `resolveExcalidraw`/`diagramFigure`/`themedImg`. `.dark.<ext>` sibling → theme swap; `.uk.<ext>` sibling → language swap. `.excalidraw.md` excluded from pages; `.excalidraw` JSON not shipped. Full guide: `docs/EXCALIDRAW.md`.
- **Image notes**: a bilingual SVG or Excalidraw embed followed immediately by `<!-- image-note: original.jpeg -->` becomes one `.image-note` figure with a native-radio `Diagram / Original` switch (diagram first, no JS required). The source photo's build-time dimensions reserve one shared stage, so switching cannot reflow the article. `npm run validate:image-notes` blocks dev/build on missing bilingual assets, geometry/privacy/accessibility problems, unsafe SVGs, incomplete exports, or a diagram over the 64KB inline ceiling. Workflow: `docs/CONTENT-WORKFLOW.md → Image notes`; renderer: `imageNoteHtml()`; validator: `scripts/validate-image-notes.mjs`.

## Language toggle

Sidebar flag switch (English default / Ukrainian). `components/T.tsx` renders both languages as spans; CSS on `html[data-lang]` shows the active one (choice persisted in localStorage, restored pre-paint by inline script in `app/layout.tsx`; a `?lang=` query param overrides it without writing it back). Titles translate via `title_uk:` frontmatter (`ukTitle()` in `lib/vault.ts`). Fixed UI strings live in `lib/ui-strings.ts` (`ui` dict of `{en, uk}` pairs — spread into `<T {...ui.key} />`; add a key there instead of hard-coding English). Dates: `displayDate` / `displayDateUk` in `lib/dates.ts`, wrapped in `<T>`. No routing, no double build. Section bodies use a sibling `main.uk.md` and entry bodies a sibling `<name>.uk.md` (read into `contentUk`, rendered in a `.lang-uk` block with `lang="uk"`). Every note should carry its `.uk.md` translation — it's part of the content-intake workflow, not optional. `<html lang="en">` never changes.

**Counted nouns** (`lib/plural.ts`, tested): "14 notes" / "14 нотаток". `lib/ui-strings.ts` holds FIXED pairs, so any string with a number in it comes from here instead — `noteCount(n)` returns a `{en, uk}` pair ready to spread into `<T>`. Ukrainian has three forms and the teens are the trap (11–14 take the `many` form despite ending in 1–4, while 21–24 follow their last digit). A missing noun is invisible to an English reader.

The element carrying `.lang-en`/`.lang-uk` must never be given a `display` (`docs/DESIGN-SYSTEM.md`). A type that receives the section's `body` prop must render it as ONE node and never split the pair.
